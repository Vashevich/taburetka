# Табуретка — инструкция для Claude и других ИИ

Планировщик комнаты из параметрических болванок мебели: 3D в браузере, VR и AR на одной странице.
Сайт: https://vashevich.github.io/taburetka/ (GitHub Pages из ветки `main`, сборки нет).
Проект офиса OFFX: правила работы, журнал и роли — в репозитории `Vashevich/OFFX`, файл `ПРИВЕТ.md`.

## Файлы
| Файл | Что в нём |
|---|---|
| `index.html` | разметка: панели, кнопки, importmap three.js 0.170 |
| `style.css` | стили (вид взят из VRtrip) |
| `js/app.js` | вся логика (≈ 3200 строк) |
| `js/furniture.js` | каталог болванок: 65 предметов, 11 разделов, построение геометрии, ручки частей (`partsOf`). **Общий с VRtrip** (`Vashevich/vrtrip`, `furniture.js`) |
| `tests/smoke.py` | автотест в Chromium: сцена, кнопки, ошибки JavaScript |
| `.github/workflows/smoke.yml` | автотест на GitHub при выкладке |

## Карта `js/app.js`
Разделы отмечены строками `// ───── название ─────`, ищи по ним.

| Раздел | О чём |
|---|---|
| сцена | рендер, камера, свет |
| состояние | `state`, сохранение проекта (браузер, JSON, ссылка) |
| комната | стены, пол, проёмы |
| предметы | постановка болванок, `fillItem`, магнит к стенам и соседям |
| камеры и вид | перспектива, «План» |
| лучи и выбор | выбор предмета лучом |
| выделение и «ручки» | гамбол (`addGumball`, `syncGizmo`), Push/Pull, ручки частей |
| рулетка | размеры с привязкой |
| указатель (мышь / палец) | перетаскивание и протяжка ручек |
| интерфейс | панели, каталог, кнопки |
| WebXR: VR и AR | шлем, контроллеры, AR на полу |
| запуск | старт |

## Правила работы
- Табуретка — только болванки: загрузку моделей из интернета и файлов не добавляем (решение Сергея).
- Главный режим — сквозной (passthrough) в шлеме; движение в нём делаем бережно.
- **Общие файлы с VRtrip** (`furniture.js`; дальше — гамбол): правка делается сразу в обоих репозиториях одним и тем же текстом. Гамбол в VRtrip уже вынесен в модуль `gumball.js` — Табуретке стоит перейти на него при следующей правке гамбола.
- **Проверка:** `python -m http.server 8767 &` и `python -u tests/smoke.py`.
- **Выкладка:** высокий риск (правило 11 офиса) — в `main` по слову Сергея или после проверки ★ Толи; иначе ветка.
- Сохранения пользователя меняются только с обратной совместимостью.
